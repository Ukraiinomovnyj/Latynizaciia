About this system

Ukrainian Latynytsia (Ukrainian: латинка, латиниця) is a complete Latin-script orthography for the Ukrainian language. It is not another romanization or transliteration standard for catalogues and road signs — systems such as ISO 9, BGN/PCGN or the Ukrainian national “passport” transliteration exist for identification, not for writing. This proposal is designed to be written in: a full alphabet with spelling rules, built on one principle — one phoneme, one letter.

The alphabet is a structural mirror of Ukrainian Cyrillic. Every Cyrillic function has an exact Latin counterpart, so conversion between the two scripts is reversible and fully algorithmic. The system uses 32 active letters and just two rules. Palatalization and iotation are carried by the trema on vowels (я/ю/є/ьо → ä/ü/ë/ö, ї → ï) and the apostrophe after consonants (ь → ’). The haček marks the three sibilants č, š, ž as independent phonemes. Four letters are reassigned on velar logic — X = х, H = г, G = ґ — following Czech and international transcription practice. Ukrainian щ [ʂtʂ] is analysed as a two-phoneme cluster and written šč, which sets Ukrainian apart from Russian щ [ɕː].

The result has zero digraphs for native phonemes and needs a single dead key (the trema) for everyday typing; every trema letter already exists on German, French and Nordic keyboard layouts. Compared with the Polish model (sz, cz, szcz, ł, ń, ś …) the script is markedly more compact — Щебрешин is Ščebrešyn here versus Polish Szczebrzeszyn — while staying close to the Czech use of the haček. Q and W are held in reserve for future extensions.

This is a technical, apolitical proposal — a ready-made orthographic tool, with authorship and date fixed for priority. Version 4.0 is archived on Zenodo under CC BY 4.0. The full white paper below is in Ukrainian.

Abstract

This document presents a phonemic Latin script for the Ukrainian language, designed as a structural mirror of the Cyrillic alphabet. The system maps each Ukrainian phoneme to exactly one Latin letter or diacritical variant, achieving zero digraphs for native phonemes. Two mechanisms handle palatalization and iotation: the trema (¨) on vowels and the apostrophe (') after consonants. The haček (ˇ) marks three sibilant phonemes (č, š, ž) that represent independent sounds rather than palatalized variants. The script uses 32 active letters with 2 reserved (Q, W) for future use. The affricate cluster šč represents щ [ʂtʂ], following the same logic as dž = дж and dz = дз. This is a technical proposal, not a political manifesto - it offers a ready-made orthographic tool should the need arise.

1. Вступ і мотивація

1.1. Історичний контекст

Латинізація слов'янських мов - не новація, а історична норма для західної гілки. Чеська, польська, хорватська, словенська та словацька мови використовують латиницю, зберігаючи при цьому слов'янську фонологічну ідентичність. Перехід від кирилиці до латиниці здійснили румуни (XIX ст.), турки (1928), молдовани (1989), а процес латинізації казахської мови триває зараз.

Українська мова історично мала контакти з латиницею: від "латинки" Йосипа Лозинського (1834) до різноманітних транслітераційних систем XX-XXI століть. Жодна з них, однак, не була спроектована як повноцінна орфографічна система з фонемним принципом.

1.2. Сучасний контекст

Війна Росії проти України, курс на європейську інтеграцію створюють унікальний історичний момент для переосмислення інструментів культурної ідентичності. Латиниця - один із таких інструментів: вона зближує Україну із західнослов'янськими сусідами та широшим європейським контекстом.

Цей документ не закликає до негайного переходу. Він пропонує технічне рішення - ретельно спроектовану систему, яка може бути використана, коли суспільство визнає це доцільним. Авторство та дата фіксуються для пріоритету.

1.3. Цілі пропозиції

Створити фонемну латинську орфографію для української мови, яка: (1) зберігає принцип «одна фонема = одна літера»; (2) є структурним дзеркалом кирилиці; (3) мінімізує кількість діакритичних знаків; (4) доступна на стандартних клавіатурах; (5) не створює хибних асоціацій для читачів інших слов'янських латиниць.

2. Огляд існуючих систем латинізації

Існуючі системи транслітерації та романізації української мови можна поділити на три категорії.

2.1. Наукова транслітерація (ISO 9)

Міжнародний стандарт ISO 9 забезпечує оборотну транслітерацію кирилиці, але використовує велику кількість діакритик і не призначений для повсякденного письма. Наприклад, щ = šč, що збігається з нашим рішенням, але загальна система надто перевантажена для орфографічного використання.

2.2. Паспортна транслітерація (КМУ 2010)

Офіційна система для паспортів та дорожніх знаків. Використовує диграфи (sh, ch, zh, shch) і є необоротною: кілька кириличних літер можуть давати однаковий латинський запис. Придатна для ідентифікації, але не для орфографії.

2.3. Польська та чеська моделі

Польська модель активно використовує диграфи (sz, cz, szcz, ch) і спеціальні літери (ł, ń, ś, ź, ć). Чеська модель спирається на гачек (ˇ) для шиплячих і є значно компактнішою. Наша система бере за основу чеський підхід, розширюючи його тремою та апострофом для палаталізації.

2.4. Критерії порівняння

Ключові метрики для оцінки систем: (1) кількість диграфів; (2) оборотність (чи можна однозначно відновити кирилицю); (3) клавіатурна доступність; (4) середня кількість символів на слово; (5) відсутність хибних асоціацій для іншомовних читачів.

3. Дизайн-принципи

3.1. Одна фонема = одна літера

Система повністю відмовляється від диграфів для позначення українських фонем. Кожен самостійний звук має рівно одне графічне позначення. Це досягається трьома механізмами: тремою (¨) для голосних, апострофом (') для м'якості приголосних та гачеком (ˇ) для трьох шиплячих фонем.

3.2. Структурна симетрія з кирилицею

Система є структурним дзеркалом кириличного алфавіту. Кожна функція кирилиці має точний аналог у латиниці: я/ю/є/ьо → ä/ü/ë/ö (трема); ь → апостроф; ї → ï; розділовий апостроф → апостроф перед трема-голосною. Ця симетрія забезпечує оборотність конверсії та зберігає інтуїцію носіїв мови.

3.3. Мінімізація діакритик

Використовуються лише дві діакритики: трема (¨) та гачек (ˇ). Трема - єдина мертва клавіша, необхідна для повсякденного введення. Гачек для č, š, ž доступний через compose-послідовності або як додаткова мертва клавіша. Усі літери з тремою (ä, ö, ü, ë, ï) вже присутні на німецькій, французькій та скандинавських розкладках.

3.4. Перепризначення літер: велярний принцип

Українська має чотири фонеми, які потребують нестандартного маппінгу: г [ɦ], ґ [g], х [x]. Рішення: H = г та G = ґ (як у чеській), X = х. Вибір X для [x] спирається на міжнародну конвенцію: грецька χ (хі) = [x], китайський піньїнь X = [ɕ], численні транскрипційні системи використовують X для велярного фрикатива.

3.5. Щ як кластер, а не фонема

Ключове рішення системи: українська щ [ʂtʂ] трактується як кластер двох фонем (ш + ч), а не як одинична фонема. Це відрізняє українську від російської, де щ = [ɕː] (один довгий звук). Запис: šč - дві літери для двох фонем, за тією самою логікою, що dž = дж і dz = дз. Принцип «один звук = одна літера» не порушується.

Альтернативний запис: літера Q може бути використана як однолітерне позначення щ (Q = щ) для досягнення більшої компактності. Це рішення залишається відкритим для майбутніх версій системи. Детальніше - див. розділ 9.

4. Повний опис системи

4.1. Два головних правила

Правило 1: Трема (¨) на голосній

Пом'якшує попередню приголосну (як я/ю/є/ьо в кирилиці). На початку слова або після голосної дає йотацію [j + голосна].

Правило 2: Апостроф (') після приголосної

М'якість без голосної (як ь в кирилиці). Використовується тільки наприкінці слова або перед приголосною.

Мнемоніка

Є голосна після м'якої → трема на голосній (tä). Нема голосної → апостроф після приголосної (t'). Апостроф перед трема-голосною → розділовий (п'ять = p'ät').

4.2. Детальні правила

Трема на голосній (ä, ë, ï, ö, ü)

Після приголосної: пом'якшує її. täžko = тяжко, lüdyna = людина, söhodni = сьогодні.

На початку слова: [j + голосна]. äbluko = яблуко, ünak = юнак, ëdnis't' = єдність.

Після голосної: [j + голосна]. moä = моя, tvoë = твоє.

Після розділового апострофа: йотація, приголосна залишається твердою. p'ät' = п'ять, m'äso = м'ясо.

Ï (ï) = ї: завжди [ji], незалежно від позиції. Ukraïna, ïžak, vyïzd.

Апостроф після приголосної (= м'який знак)

На кінці слова: kin' = кінь, včytel' = вчитель, sil' = сіль, misc' = місць.

Перед приголосною: L'viv = Львів, t'mänyj = тьмяний.

Як розрізнити два типи апострофа

Правило однозначне: апостроф перед трема-голосною (ä, ü, ë, ï) = розділовий. Апостроф перед приголосною або на кінці слова = м'якість. Ці два випадки ніколи не перетинаються.

Перепризначені літери

X = х [x] - велярний фрикативний. Xarkiv = Харків, xlib = хліб.

H = г [ɦ] - фрикативний (як у чеській). hovoryty = говорити.

G = ґ [g] - зімкнений. ganok = ґанок.

Гачек - тільки для шиплячих

Č č = ч [tʂ], Š š = ш [ʂ], Ž ž = ж [ʐ]. Гачек позначає окремі фонеми, а не м'які варіанти.

Щ = šč (кластер)

Українська щ [ʂtʂ] записується як šč - послідовність двох фонем. Приклади: ščastä = щастя, plošča = площа, boršč = борщ, šče = ще.

Подовження та дж/дз

Подовжені м'які приголосні пишуться подвоєнням + трема: žyttä = життя, znannä = знання, sillü = сіллю.

Дж та дз пишуться як dž та dz: džmil' = джміль, dzvin = дзвін. Двозначність (одна чи дві фонеми) ідентична кириличній.

7. Практичні аспекти

7.1. Клавіатура

Система потребує одну мертву клавішу - трему (¨). Апостроф є на кожній клавіатурі. Гачек для č, š, ž доступний через compose-послідовності або як додаткова мертва клавіша. Усі трема-літери (ä, ö, ü, ë, ï) уже наявні на німецькій, французькій та скандинавських розкладках. Усі символи присутні в Unicode.

7.2. Unicode-сумісність

Кожна літера системи - це стандартний символ Unicode, а не комбінація базової літери з діакритикою. Це гарантує коректне відображення, сортування, пошук та індексацію у всіх сучасних системах.

7.3. Алгоритм конверсії

Конверсія кирилиця → латиниця та зворотна є повністю алгоритмізовною. Оборотність системи дозволяє створити автоматичний конвертер без втрати інформації. Основні правила конверсії: (1) пряма заміна за таблицею алфавіту; (2) контекстний аналіз для м'якого знака (ь → апостроф); (3) контекстний аналіз для я/ю/є/ї → трема-голосні. Реалізація конвертера - окремий технічний додаток до цього документа.

8. Обмеження та відкриті питання

8.1. Подвійна функція апострофа

Апостроф виконує дві ролі: м'якість (перед приголосною/кінець слова) та розділовий знак (перед трема-голосною). Хоча контекст завжди однозначний, візуально це один і той самий символ. Можливе рішення - використання різних символів (наприклад, ' для м'якості та ' для розділового), але це ускладнює введення.

8.2. Двозначність dž/dz

Запис dž і dz не розрізняє африкати (джміль, дзвін) та послідовності двох фонем (підживити, підзолити). Ця двозначність ідентична кириличній і є успадкованою, а не новою проблемою. Можливий напрямок вирішення - введення окремих літер для африкатів у майбутніх версіях.

8.3. Візуальна вага šč

Кластер šč для позначення щ візуально важкий, особливо у високочастотних словах: ščo (що), šče (ще). Це свідома ціна за звільнення X для більш інтуїтивного маппінгу X = х та збереження теоретичної чистоти (дві фонеми → дві літери). Альтернативне рішення - використання Q для щ - описане в розділі 9.

9. Резервні літери та альтернативи

9.1. Q - потенційне позначення щ

Літера Q не використовується в основній системі і може бути задіяна як однолітерне позначення щ. Це дозволило б скоротити запис високочастотних слів: qo = що, qe = ще, qastä = щастя, ploqa = площа, borq = борщ. Вибір між šč та Q залишається відкритим і залежить від пріоритету: теоретична чистота (šč) чи практична компактність (Q).

9.2. W - відкритий резерв

Літера W залишається повністю вільною. Можливі майбутні застосування: (1) позначення алофона [w] для В у певних позиціях (якщо літературна норма визнає це розрізнення); (2) адаптація для діалектних записів; (3) запозичення з інших мов. Наявність вільної літери в алфавіті забезпечує гнучкість системи для майбутнього розвитку.

10. Підсумок

32 літери (27 базових + 5 трема-голосних), з яких 3 мають гачек (č, š, ž).

Апостроф виконує дві функції: м'якість (перед приголосною/кінець слова) та розділовий знак (перед трема-голосною). Контекст завжди однозначний.

Перепризначені літери: X = х, H = г, G = ґ.

Кластер: Щ = šč (дві фонеми, дві літери).

Резервні: Q (потенційно щ), W (відкритий резерв).

0 диграфів для позначення українських фонем (dž та dz - успадкована двозначність з кирилиці).
